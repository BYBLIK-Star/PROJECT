# Проект: «100 заключенных и коробки»

Это колледжский проект по известной задаче теории вероятностей «100 заключенных и 100 коробок».  
Приложение показывает, как работает задача на практике, позволяет запускать симуляцию, сравнивать стратегии и сохранять статистику игр.

## О проекте

Суть задачи:

- есть `N` заключенных и `N` коробок;
- в каждой коробке лежит номер одного из заключенных;
- каждый заключенный может открыть не больше `N / 2` коробок;
- если каждый заключенный найдет свой номер, выигрывают все;
- если хотя бы один не найдет свой номер, проигрывает вся группа.

Главная идея проекта - показать, что стратегия следования по циклу дает намного более высокий шанс на успех, чем случайный выбор коробок.

## Возможности приложения

- графический интерфейс на `customtkinter`;
- ручной режим прохождения;
- автоматический режим со стратегией цикла;
- автоматический случайный режим;
- выбор количества заключенных;
- подсчет общей статистики игр;
- хранение статистики в `SQLite`;
- экспорт статистики в `JSON`, `CSV` и `XML`;
- вывод теоретической вероятности успеха для разных стратегий.

## Как запустить

1. Перейти в папку проекта.
2. Активировать виртуальное окружение при необходимости.
3. Установить зависимости:

```bash
pip install customtkinter pillow cairosvg
```

4. Запустить приложение:

```bash
python PROJECT/prisoners_app2.py
```

## Как пользоваться

После запуска приложения можно:

- начать новую игру;
- выбрать количество заключенных;
- пройти симуляцию вручную;
- включить автоматическую стратегию:
  - `Цикл` - оптимальная стратегия;
  - `Случайно` - случайный выбор коробок;
- посмотреть статистику сыгранных партий;
- экспортировать результаты.

## Математическая идея

В проекте сравниваются две стратегии:

1. `Случайная стратегия` - каждый заключенный открывает случайные коробки.  
   Вероятность общего успеха крайне мала.

2. `Стратегия цикла` - заключенный сначала открывает коробку со своим номером, затем переходит к номеру, найденному внутри, и так далее.  
   Для 100 заключенных вероятность общего успеха составляет примерно `31%`, что значительно выше случайной стратегии.

## Хранение статистики

Приложение сохраняет:

- общее количество игр;
- число побед и поражений;
- число спасенных и потерянных заключенных;
- статистику для разных значений `N`;
- историю сыгранных партий.

## Экспорт данных

Статистика может быть экспортирована в:

- `JSON`
- `CSV`
- `XML`

Файлы сохраняются в папку `PROJECT/exports/`.
